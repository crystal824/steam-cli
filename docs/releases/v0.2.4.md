# v0.2.4

**评论功能修复：`review post` 此前从未真正发布过任何评论 / Reviews now actually publish**

## 中文

**1. `review post` 修复：以前是「静默空操作」**

旧版本把评论提交到 `steamcommunity.com/profiles/<steamid>/recommended/`，而那个地址只是**一个网页**：POST 过去会返回 HTTP 200 + HTML，什么都不会保存。因为代码只检查 `status_code == 200`，它会打印 `Review posted.` 却什么都没发布——最隐蔽的一类 bug：失败伪装成成功（此前它只跑过 `--dry-run`，所以一直没暴露）。

现在改用 store 前端 `main.js::RecommendGame()` 真正调用的接口：

```
POST https://store.steampowered.com/friends/recommendgame
```

并且**必须**解析响应：只有 JSON 里的 `success: true` 才算成功；Steam 自己的拒绝（例如「该产品需先游玩至少 5 分钟」）会以结构化错误 `review_rejected` 抛出；返回非 JSON（说明端点又变了）会抛 `network_error`，而不是又一次假装成功。发布成功后会回读你的资料页确认。

**2. `--mine` 修复，并新增 `steam review mine`**

旧实现的 `--mine` 是在游戏的**公开评论流**里筛自己，而那个流只返回最新一页并按语言过滤——热门游戏有上百万条评论，加上你的评论是中文、过滤条件却是 `english`，所以它**结构上不可能命中**。现在改为读取你自己资料页上的评论：`steam review mine` 可以列出你发过的全部评论（游戏名、评价、日期、时长、可见性）。

**3. 新增参数**

- `review post --language/-L <语言代码>`：标注评论语言（默认 `schinese`，中文评论保持默认即可）
- `review post --private`：以「仅自己可见」发布
- `review post --verify/--no-verify`：发布后是否回读资料页核对（默认开启）
- `review list -L all`：公开评论流默认只显示英文，加 `-L all` 才能看到中文评论；同时新增 `-n/--limit` 与「Posted」日期列

**升级说明**：`steam review post` 现在**真的会发布**（此前是空操作）。如果你的脚本或流程依赖它「看起来成功」，请留意这一点：评论一旦发出即为公开可见，而且该命令本身没有二次确认提示。发布评论需要该产品至少 5 分钟游玩记录。其余无需迁移。

## English

**1. `review post` fixed: it used to be a silent no-op**

The old code posted reviews to `steamcommunity.com/profiles/<steamid>/recommended/`, which is only a **page**: a POST there returns HTTP 200 with HTML and saves nothing. Since the code tested nothing but `status_code == 200`, it printed `Review posted.` while publishing nothing — the worst kind of bug, a failure that looks like a success. It had only ever been exercised with `--dry-run`, which is why it survived this long.

It now uses the endpoint the store front-end actually calls (`main.js::RecommendGame()`):

```
POST https://store.steampowered.com/friends/recommendgame
```

and it **parses the response**: only `{"success": true}` counts. Steam's own rejections (for example "You need to have used this product for at least 5 minutes before posting a review for it") surface as the structured `review_rejected` error, and a non-JSON reply (the endpoint moved again) raises `network_error` instead of pretending success. After a successful post the review is read back from your profile page to confirm it landed.

**2. `--mine` fixed, plus a new `steam review mine`**

The old `--mine` filtered the game's **public review feed**, which only ever returns the newest page and filters by language — a popular title has over a million reviews, and the filter was `english` while the account writes Chinese, so it could **never** match. Reviews are now read from your own profile page: `steam review mine` lists every review you have posted (game name, verdict, date, playtime, visibility).

**3. New options**

- `review post --language/-L <code>`: language the text is written in (default `schinese`)
- `review post --private`: publish with "private" visibility
- `review post --verify/--no-verify`: read the review back from your profile afterwards (on by default)
- `review list -L all`: the public feed is English-only by default; `-L all` includes Chinese reviews. Also new: `-n/--limit` and a Posted column.

**Upgrading**: `steam review post` now **really publishes** (it used to do nothing). If a script relied on it "appearing to succeed", note that a published review is public immediately and the command has no confirmation prompt. A review requires at least 5 minutes of playtime on the product. Nothing else to migrate.
