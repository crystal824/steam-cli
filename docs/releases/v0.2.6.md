# v0.2.6

**`steam login` 内置 Steam 现代登录流程；并修复会话探针与页面解析两处缺陷 / `steam login` runs Steam's current login flow, plus two probe/parsing fixes**

## 中文

**1. `steam login` 现在真的能登录**

此前它走 ValvePython 的 `steam.webauth.WebAuth`，而那条路径指向已被 Valve 退役的 community `/login/dologin/`：Steam 仍会应答（密码 + 2FA 正确时返回 success），但**不会铸出任何可用会话**——命令可能"报成功"却什么都没认证。可用的流程原本只存在于 `tools/steam_modern_login.py`。

如今流程内置于 CLI：RSA 公钥交换 → `BeginAuthSessionViaCredentials` → 手机 App 批准或 `UpdateAuthSessionWithSteamGuardCode` → `PollAuthSessionStatus` 取 refresh token → `jwt/finalizelogin` → 逐域 settoken（**每个请求体都必须带 `steamID`**，缺它 Steam 返回 `{"result": 8}` 且不写 cookie）。失败以结构化错误 `login_failed` 抛出，且**只有商店接受新会话后才落盘**，不会留下半坏状态。

**2. 新增 `steam refresh --remint`**

登录会拿到长期 refresh token，因此**仅仅是会话过期**时用 `steam refresh --remint` 重建即可：不需要密码，不需要 2FA。`steam login` 新增 `--code`（不传则交互提示，空回车表示改用手机 App 批准）。

**3. 修复「会话有效性」探针的假警报**

旧探针不跟随跳转、只认 HTTP 200，而商店对 `/account/` 的首次请求经常先返回 302 到自身（引导 cookie），于是**健康会话被判为过期**——`steam status` 因此长期误报，还白白触发过重新登录。现在统一走 `auth.probe_authed()`：跟随跳转，且仅在落地页含 `/login/` 时判为失效。

**4. 修复语言相关的页面解析**

重新铸造的会话会带上账号的 `Steam_Language`，`steamcommunity.com/profiles/<id>/recommended/` 随即以该语言渲染（中文账号看到的是 推荐 / 发布于 / 小时 / 可见性）。按英文标签写的解析器会**静默解析出空字段**——`steam review mine` 的日期、时长、可见性列就中过一次。现在请求固定 `?l=english`；「推荐 / 不推荐」改用 `icon_thumbsUp/Down` 图标判定（图标名不随语言变化，且中文「不推荐」包含「推荐」，纯文本匹配本身就是坑）。`tools/check_licenses.py` 出于同样原因固定英文渲染（否则获取方式列会显示「零售 / Steam 商店」）。

**5. `tools/` 脚本改为薄封装**

`steam_modern_login.py` / `steam_remint_session.py` 现在调用 CLI 内同一份实现，仅保留「逐步输出 JSON」的形态供自动化使用，并新增 `STEAM_CLI_PASSWORD` 支持无人值守登录。

**升级说明**：`steam login` 的行为发生变化——此前可能「成功」却产生无效会话，现在真正建立可用会话。会话过期请优先用 `steam refresh --remint`。另请知悉：用同一个 refresh token 重铸会**轮换会话并让此前存储的 cookie 失效**，因此重铸失败会导致当下没有可用会话（重试即可，或改用 `steam login`）。

## English

**1. `steam login` actually logs in now**

It drove ValvePython's `steam.webauth.WebAuth`, which posts to the community `/login/dologin/` endpoint Valve retired: Steam still answers it (success, after a correct password and 2FA code) but mints **no usable session**, so the command could report success while authenticating nothing. The working flow existed only in `tools/steam_modern_login.py`.

It is in the CLI now: RSA key exchange → `BeginAuthSessionViaCredentials` → app approval or `UpdateAuthSessionWithSteamGuardCode` → `PollAuthSessionStatus` for the refresh token → `jwt/finalizelogin` → the per-domain settoken calls (**every settoken body must carry `steamID`**; without it Steam answers `{"result": 8}` and writes no cookie). Failures surface as the structured `login_failed` error, and the session is only persisted **after the store accepts it** — nothing half-broken is written.

**2. New: `steam refresh --remint`**

A login yields a long-lived refresh token, so a session that merely expired is rebuilt with `steam refresh --remint` — no password, no 2FA. `steam login` gained `--code` (prompted for when omitted; an empty answer means "I will approve it in the Steam app instead").

**3. Fixed: the session-validity probe cried wolf**

The old probe did not follow redirects and required a bare HTTP 200, while the store frequently answers a first request to `/account/` with a 302 to itself while bootstrapping cookies — so **healthy sessions were reported as expired**, `steam status` said `Session valid: no`, and re-logins were triggered for nothing. Probes now go through `auth.probe_authed()`: follow redirects, and only treat a landing on `/login/` as unauthenticated.

**4. Fixed: language-dependent page parsing**

A re-minted session carries the account's `Steam_Language`, so `steamcommunity.com/profiles/<id>/recommended/` renders in that language (a Chinese account sees 推荐 / 发布于 / 小时 / 可见性) and a parser written against English labels **silently returns empty fields** — which is exactly what happened to the date, playtime and visibility columns of `steam review mine`. The page is now requested with `?l=english`, and the 推荐/不推荐 verdict is read from the `icon_thumbsUp/Down` icon files, which do not move between languages (the Chinese word for "not recommended" contains the one for "recommended", so text matching is a trap of its own). `tools/check_licenses.py` pins English for the same reason — its acquisition column reads 零售 / Steam 商店 otherwise.

**5. `tools/` scripts are wrappers now**

`steam_modern_login.py` / `steam_remint_session.py` call the same implementation as the CLI and keep their one-JSON-object-per-step output for automation. `STEAM_CLI_PASSWORD` supports unattended logins.

**Upgrading**: `steam login` behaves differently — it used to "succeed" and produce an unusable session, and now establishes a real one. Prefer `steam refresh --remint` for an expired session. Two things to know: re-minting with the same refresh token **rotates the session and invalidates the previously stored cookies** (a failed re-mint leaves you with no session until one succeeds), and `steam logout` keeps the refresh token on purpose while `steam revoke-all` wipes it.
