# v0.2.3

**发布说明改为中英双语 / Release notes are now bilingual**

## 中文

**1. 双语规范**

从此以后，每个版本的发布说明都用中文和英文各写一遍（中文在前、英文在后），两部分内容对等。`docs/releases/README.md` 里写明了模板与要求，方便以后照做。

**2. 修正已发布版本的文案，不再需要 token**

发布任务现在从 `main` 读取 `cliff.toml` 与 `docs/releases/`（它们属于工具与文档，不是被发布的代码）。因此修正某个已发布版本的说明，只要改文件、重推该 tag 即可——不需要 GitHub API token，也不用碰网页后台。

**3. 历史版本说明**

`v0.2.0`、`v0.2.1` 的说明文件仍是纯英文，它们是双语规范确立之前写的；对应 Release 页面保持原样，不再修改。

**升级说明**：无需任何操作。本版本只涉及发布流程与文档，CLI、Python 包与技能归档的行为与 0.2.2 完全一致。

## English

**1. Bilingual by convention**

From now on every release note is written twice — Chinese first, then English, with both halves equivalent. `docs/releases/README.md` documents the template and the requirements.

**2. Correcting a published release no longer needs a token**

The release job now reads `cliff.toml` and `docs/releases/` from `main` (both are tooling and documentation, not released code). Fixing the notes of an already published release is therefore just edit-the-file and re-push the tag — no GitHub API token, no visiting the web UI.

**3. Older notes**

`v0.2.0` and `v0.2.1` keep English-only notes; they were written before the bilingual convention existed and their release pages stay as they are.

**Upgrading**: nothing to do. This release only touches release tooling and documentation; the CLI, the Python package and the skill archive behave exactly as in 0.2.2.
