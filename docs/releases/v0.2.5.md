# v0.2.5

**新增「游戏评价现状」查询，商店区域/语言改为跟随账号 / Review summaries, and the store region now follows your account**

## 中文

**1. 新增 `steam review summary <appid|标题>`**

一条命令读懂一款游戏的口碑：

```
steam review summary 1144200 [-L all] [-s 8] [-d 30] [--json]
```

- **档位与好评率**：仿 Steam 中文档位（好评如潮 / 特别好评 / 多半好评 / 褒贬不一 / 多半差评 …），附好评率与总条数
- **近期口碑**：`day_range` 参数已被 Steam 废止（返回的数据与全时段完全相同），因此近期数据改为客户端抽样最新评测，样本过多时会标注「未全量」
- **好评/差评样本**：来自「最有帮助 + 最新」两路合并池，去重后按票数排序，附带票数、语言、游戏时长
- **`--json`**：结构化输出，便于脚本处理

支持标题查询（`steam review summary 黑神话`），中文名会走简体中文商店搜索。

**2. 商店区域与语言不再硬编码美区**

此前所有商店请求都写死 `l=english&cc=us`，中文账号看到的是美元价和英文文案。现在改为**跟随账号**：

- 区域取自账号页 `country_code`（`steam status` 本就会请求的那个页面），缓存 1 天
- 语言由国家推导（cn→schinese，jp→japanese，tw/hk→tchinese…）
- 覆盖方式：单次调用 `steam price <id> --cc us`；单个 shell `STEAM_CLI_CC` / `STEAM_CLI_LANG`；长期 `steam config region set cn --lang schinese`（`show` 查看来源，`clear` 恢复跟随）
- `steam status` 新增 Region 行；`steam doctor` 探针同样按区域发起

**3. 顺带修掉的两个坑**

- 小众游戏的评测列表与「最有帮助」排序会异常收缩（某 374 条评测的游戏只排出 1 条），且 `review_type` 过滤并不总被遵守、首页需要显式 `cursor=*` —— 采样逻辑已按实测行为加固
- 中文标题解析：社区搜索索引对 CJK 名称不可靠（曾把「黑神话」解析成另一款同名山寨），现在优先走简体中文商店搜索

**升级说明**：商店相关的价格与文案会从「美元 + 英文」变为账号所在区域（本仓库维护者的账号：人民币 + 简体中文）。若有脚本依赖美元输出，请显式传 `--cc us`。`review post` / `review list` 的 `-L` 默认值改为账号商店语言（中文账号即 `schinese`，行为与此前一致）。

## English

**1. New: `steam review summary <appid|title>`**

One command to read a game's reception:

```
steam review summary 1144200 [-L all] [-s 8] [-d 30] [--json]
```

- **Score band and positive share** in Steam's own wording (Overwhelmingly Positive … Mixed … Mostly Negative), with the total review count
- **Recent picture**: Steam retired the `day_range` parameter (it returns the all-time numbers verbatim), so the recent window is sampled client-side from the newest reviews and flagged when the window holds more than the sample cap
- **Pros/cons samples**: merged from the "most helpful" and newest listings, deduped, ranked by votes, each with votes / language / playtime
- **`--json`** for scripted use

Titles work as well as appids (`steam review summary "Elden Ring"`), and CJK titles are resolved through the Simplified-Chinese store search.

**2. The store region and language are no longer hardcoded to the US**

Every store request used to send `l=english&cc=us`, so a non-US account was quoted USD and got English text. Now it follows the account:

- the country comes from the account page's `country_code` (the page `steam status` already fetches), cached for a day
- the language is derived from the country (cn→schinese, jp→japanese, tw/hk→tchinese, …)
- override per call (`steam price <id> --cc us`), per shell (`STEAM_CLI_CC` / `STEAM_CLI_LANG`), or permanently (`steam config region set cn --lang schinese`; `show` for the source, `clear` to follow the account again)
- `steam status` gained a Region line, and `steam doctor` probes with the region's parameters

**3. Two long-standing traps fixed along the way**

- Review listings collapse on obscure titles (a 374-review game ranked exactly one "most helpful" review), `review_type` filtering is not honoured consistently, and the first page needs an explicit `cursor=*` — the sampler is now hardened against all three
- CJK title resolution: the community search index is unreliable for Chinese names (it once resolved 黑神话 to an unrelated knock-off), so those queries now go to the Simplified-Chinese store search first

**Upgrading**: store prices and text change from USD/English to the account's region (this repository's owner: CNY, Simplified Chinese). Scripts that depend on USD output should pass `--cc us` explicitly. `review post` / `review list` default `-L` to the account's store language (schinese for a Chinese account, i.e. unchanged in practice).
