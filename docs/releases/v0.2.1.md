Housekeeping release: **the changelog is now maintained by CI** instead of by hand.

## What changed

The release workflow rendered `CHANGELOG.md` with git-cliff but only used the result
as the GitHub Release body, so the copy in the repository drifted from the released
notes and had to be edited manually.

Now, after building and publishing a release, the workflow copies the rendered
changelog onto `main` and commits it. Two small safeguards keep it predictable:

- the commit is skipped when nothing changed (no empty commits);
- it runs after the build and publish steps, so the released artifacts are still
  built from the tagged tree.

There are no changes to the CLI itself, the Python package or the skill archive in
this release.
